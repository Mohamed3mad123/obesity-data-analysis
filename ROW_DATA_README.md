# <span style="color: #2E86C1;">Raw Data Documentation</span>

## <span style="color: #2E86C1;">Overview</span>
This folder contains the original, unprocessed datasets (`Raw Data`) collected for the final project. These files serve as the foundational input for our data cleaning, preprocessing, and analysis pipeline using Python and SQL.

---

## <span style="color: #2E86C1;">Dataset Files</span>

* **`Diabetes Dataset – NCD-RisC.csv`**
  - **Description:** Global and country-specific data tracking diabetes prevalence, uncertainty intervals, and treatment proportions across various age groups, sourced from the NCD Risk Factor Collaboration (NCD-RisC).

* **`Obesity Dataset – NCD-RisC.csv`**
  - **Description:** Comprehensive records on adult body mass index (BMI) distributions, including obesity prevalence, underweight rates, and uncertainty intervals for Egypt, Japan, and the United States from 2000 to 2022.

* **`Physical Inactivity.csv`**
  - **Description:** Statistical indicators measuring insufficient physical activity levels across populations to analyze lifestyle correlations with health outcomes.

* **`economic_health_indicators_egypt_japan_usa_2000_2022.csv`**
  - **Description:** Macroeconomic and health system indicators—such as GDP per capita (PPP) and health expenditures—structured for comparative analysis across the three target countries from 2000 to 2022.

---

## <span style="color: #2E86C1;">Data Source Integrity & Note</span>
* All raw files are maintained in their original formats to ensure traceability and reproducibility. 
* Subsequent cleaning, transformation, and merging steps are handled via Python scripts before loading into the relational database.
