Normalized relational tables and dimensional modeling executed in SQL Server.

Open SQL_README.md 
-- Star Schema Dimension & Fact Tables Setup
CREATE DATABASE Health_Analytics;
GO
USE Health_Analytics;
GO

-- Create Dimension Tables
CREATE TABLE dbo.DimCountry (Country_Code VARCHAR(3) PRIMARY KEY, Country_Name NVARCHAR(50) NOT NULL);
CREATE TABLE dbo.DimYear ([Year] INT PRIMARY KEY);
CREATE TABLE dbo.DimSex (Sex_ID INT PRIMARY KEY, Sex_Name VARCHAR(10) UNIQUE NOT NULL);

-- Create Fact Tables (Obesity, Diabetes, Physical Inactivity, Economic)
CREATE TABLE dbo.FactObesity (
    Country_Code VARCHAR(3) NOT NULL,
    [Year] INT NOT NULL,
    Sex_ID INT NOT NULL,
    [Obesity_Prevalence] DECIMAL(20,12) NOT NULL,
    CONSTRAINT PK_FactObesity PRIMARY KEY ([Country_Code], [Year], [Sex_ID]),
    CONSTRAINT FK_FactObesity_Country FOREIGN KEY (Country_Code) REFERENCES dbo.DimCountry(Country_Code)
);

Project Objectives

  • Multi-National Trend Analysis: Track and contrast adult obesity trajectory in Egypt, Japan, and USA from 2000 to 2022.
  • Socioeconomic Correlations: Evaluate relationship between GDP per capita (PPP) and health expenditure with BMI patterns.
  • Double Burden Evaluation: Analyze simultaneous coexistence of underweight rates and severe obesity in developing profiles.
  • Data Storytelling: Deliver interactive Power BI & Tableau dashboards for clear stakeholder communication.

Core Health & Economic Indicators

Adult Obesity Prevalence
BMI ≥ 30 kg/m² with 95% uncertainty intervals (Lower & Upper limits).
GDP Per Capita (PPP)
Purchasing Power Parity economic metrics tracking national affluence.
Diabetes Prevalence (18+)
Infection rates and treatment proportions among adults (30+ yrs).
Physical Inactivity & Health Spending
Lifestyle metrics combined with per-capita healthcare expenditure.
