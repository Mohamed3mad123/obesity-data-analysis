Stage 2: Python Data Cleaning & Transformation Pipeline

Data cleaning scripts executed using Pandas & NumPy to standardize schemas.

Open PYTHON_README.md 
# Python Data Cleaning Pipeline Highlight (Pandas)
import pandas as pd
import numpy as np

# 1. Load Raw Datasets
df_obesity = pd.read_csv('Row Data/Obesity Dataset – NCD-RisC.csv')
df_economic = pd.read_csv('Row Data/economic_health_indicators_egypt_japan_usa_2000_2022.csv')

# 2. Filter Target Countries (Egypt, Japan, USA) & Date Range (2000-2022)
target_countries = ['Egypt', 'Japan', 'United States of America']
df_clean = df_obesity[df_obesity['Country'].isin(target_countries) & df_obesity['Year'].between(2000, 2022)]

# 3. Handle Missing Values & Merge Indicators
df_final = pd.merge(df_clean, df_economic, on=['Country', 'Year'], how='left')
df_final.to_csv('Cleaned Data/cleaned_obesity_indicators.csv', index=False)

Project Objectives

  • Multi-National Trend Analysis: Track and contrast adult obesity trajectory in Egypt, Japan, and USA from 2000 to 2022.
  • Socioeconomic Correlations: Evaluate relationship between GDP per capita (PPP) and health expenditure with BMI patterns.
  • Double Burden Evaluation: Analyze simultaneous coexistence of underweight rates and severe obesity in developing profiles.
  • Data Storytelling: Deliver interactive Power BI & Tableau dashboards for clear stakeholder communication.

Core Health & Economic Indicators

Infection rates and treatment proportions among adults (30+ yrs).
